# 기록 레시피 · Record Recipe

> 뭘 써야 할지 모르는 사람을 위한, **따라 쓰는 기록 레시피**

기록을 하고 싶지만 빈 페이지 앞에서 막막한 사람이 **질문 하나에 한 줄**로 기록을 시작하고, 상황에 맞는 기록 포맷(레시피)을 따라 쓰며 기록 습관을 만드는 앱이에요.

## 지금 상태
- **v0 · 팀 발표용 MVP** (2026-11-09): UI/UX 수업 팀 프로젝트 중 아이디어를 빠르게 보여 주기 위해 만든 클릭 프로토타입. `v0-team-demo` 태그로 보존해요.
- 다음: **v1 · 내가 매일 쓰는 버전** — 직접 써 보고 다듬은 뒤 다른 사람들에게 배포할 예정이에요.

## 실행 방법
`index.html`을 브라우저로 열면 돼요. 설치는 필요 없어요.

## 문서
- [PRD (v0 기준)](docs/PRD.md): 팀 발표용으로 쓴 초안이라 v1 방향에 맞춰 고칠 예정이에요.
- [결정 일지](docs/decision-log.md): 무엇을 왜 바꿨는지 기록해요.

## 출발 이야기
팀 프로젝트에서 건강 기록 앱(Body Log)을 기획하다가 **"사람들이 애초에 기록을 안 한다"**는 걸 발견했어요. 그래서 질문을 "어떻게 건강을 기록하게 할까?"에서 **"사람들은 왜 기록을 안 할까?"**로 바꿨고, 그 답으로 나온 게 기록 레시피예요.
