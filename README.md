# 기록 레시피 · Record Recipe

> 뭘 써야 할지 모르는 사람을 위한, **따라 쓰는 기록 레시피**

기록을 하고 싶지만 빈 페이지 앞에서 막막한 사람이 **질문 하나에 한 줄**로 기록을 시작하고, 상황에 맞는 기록 포맷(레시피)을 따라 쓰며 기록 습관을 만드는 앱이에요.

## 지금 상태
- **v0 · 팀 발표용 MVP** (2026-11-09): UI/UX 수업 팀 프로젝트 중 아이디어를 빠르게 보여 주기 위해 만든 클릭 프로토타입. `v0-team-demo` 브랜치에 그대로 보존해요.
- **v1 · 내가 매일 쓰는 버전** (2026-11-13, 지금 `main`): 혼자 매일 쓰는 데 필요한 것만 남기고 다듬은 버전이에요. 직접 써 보고 괜찮으면 다른 사람들에게 배포할 예정이에요.

## v1에서 바뀐 것
- **지난날의 나**: 가짜 "남들의 답" 대신, 오늘 한 줄을 쓰면 1년 전·한 달 전·일주일 전의 내가 쓴 기록이 열려요.
- **오늘의 질문 40개**: 날마다 다른 질문이 나오고, 마음에 안 들면 바꿀 수 있어요.
- **수정·삭제**: 오늘의 한 줄과 모든 기록을 고치거나 지울 수 있어요.
- **백업**: ⚙️ 설정에서 백업 파일을 내려받고 다시 불러올 수 있어요. 7일 넘게 백업을 안 하면 알려 줘요.
- **폰에 설치(PWA)**: 홈 화면에 추가하면 앱처럼 열리고, 인터넷이 없어도 열려요.
- **덜어 낸 것**: 교환일기, 여행 도장깨기, "친구랑" 레시피는 혼자 쓰는 단계라 숨겼어요. (`v0-team-demo` 브랜치에 남아 있어요)

## 실행 방법
- **컴퓨터에서 보기**: `index.html`을 브라우저로 열면 돼요.
- **폰에서 매일 쓰기**: 저장소 **Settings → Pages**에서 Branch를 `main` / `/(root)`로 저장하면 `https://yoonsdb17.github.io/record-recipe/` 주소가 생겨요. 폰으로 열고 ⚙️ 설정의 안내대로 홈 화면에 추가하세요.
- 기록은 그 기기의 브라우저에만 저장돼요. 가끔 ⚙️에서 백업해 주세요.

## 출발 이야기
팀 프로젝트에서 건강 기록 앱(Body Log)을 기획하다가 **"사람들이 애초에 기록을 안 한다"**는 걸 발견했어요. 그래서 질문을 "어떻게 건강을 기록하게 할까?"에서 **"사람들은 왜 기록을 안 할까?"**로 바꿨고, 그 답으로 나온 게 기록 레시피예요.
