# 이어서 작업하기 위한 정리 (2026-11-18)

Claude 앱에서 나눈 대화를 Claude Code로 옮기려고 정리한 문서예요.

## 1. 출발 이야기
1. UI/UX 수업 팀 프로젝트에서 건강 기록 앱 **Body Log**를 기획했어요.
2. 팀원 인터뷰에서 **사람들이 애초에 기록을 안 한다**는 걸 발견했어요.
3. 질문을 "어떻게 건강을 기록하게 할까?" → **"사람들은 왜 기록을 안 할까?"**로 바꿨어요.
   - 근거: 한국리서치 2025년 3월 조사에서 기록을 안 하는 이유 상위가 "기록할 만한 게 없어서"(17%), "꾸준히 할 동기·습관 부족"(16%)
4. 답으로 나온 게 **기록 레시피**예요. 팀은 다른 방향('우리 사이', 친구 모임 추억 기록)으로 갔고, 기록 레시피는 지영이 개인 프로젝트로 가져왔어요.

## 2. 지영의 목표
- 지영은 원래 기록을 하는 사람이에요. **직접 매일 써 보고, 괜찮다고 느끼면 다른 사람들에게 배포**하고 싶어 해요.
- 포트폴리오: 기록 레시피 = **메인 프로젝트**, 멍멍푸드맵 = 사이드 프로젝트

## 3. 단계 계획
1. **혼자 쓰는 버전** ← 지금 여기 (v1 완성)
2. **직접 써 보기 (2~4주)**: 불편한 점 메모, 며칠 연속 썼는지, 자주 쓴 레시피, 그만두고 싶었던 순간
3. **친구들에게 배포**: 로그인과 서버 저장이 필요해요(예: Supabase). 이때 "써야 열리는 남들의 답", 교환일기처럼 여럿이 쓰는 기능을 다시 검토해요.

## 4. 지금 기능 (v1)
- **오늘의 한 줄**: 날마다 바뀌는 질문 40개, 빠른 답 칩, 질문 바꾸기, 고치기
- **지난날의 나**: 오늘 한 줄을 써야 1년 전·한 달 전·일주일 전 기록이 열려요. 없으면 같은 질문의 예전 답이나 가장 오래된 기록
- **레시피 33개**: 초간단·아침·하루·감정·생각·회고·리뷰·여행 카테고리, 질문형으로 따라 쓰기, 사진·긴 글 칸, 써 본 레시피 표시, 레시피 숨기기
- **내 기록**: 이번 주 기록일, 연속 기록, 수정·삭제
- **⚙️ 설정**: 백업 파일 내려받기·불러오기·복사, 7일 넘으면 백업 알림, 숨긴 레시피 다시 보기, 홈 화면 설치 안내
- **폰 설치(PWA)**: 홈 화면 아이콘, 인터넷 없이도 열림
- 숨긴 것: 교환일기, 여행 도장깨기, "친구랑" 레시피 (`v0-team-demo` 브랜치에 있어요)
